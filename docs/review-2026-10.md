# eigencore review: correctness, performance, and capability gaps

Date: 2026-10-08. Reviewed tree: `main` at `83ca827` (v1.3.0).

Method: static review of `R/` and `src/` in four tracks (native eigen kernels,
native SVD/operator/certificate kernels, R planner/API layer, capability gap
analysis against RSpectra/Spectra, ARPACK, PRIMME, SLEPc, irlba, rsvd, geigen,
LAPACK, scipy, KrylovKit), followed by empirical probes on an installed build
(R 4.x on Linux, reference BLAS/LAPACK, RSpectra from Debian). Items marked
**confirmed** reproduced on the installed package; the rest are from code
reading. Status column refers to the `fix/correctness-review` branch; every fixed item has a regression test in `tests/testthat/test-review-regressions.R` or `test-native-hardening.R`.

## 3. Capability gaps

### P0 (blocks a "premier" claim)

1. Faithful RSpectra drop-in (now addressed for `sigma`, `opts`, function input, `lower`, `nu`/`nv`, non-convergence warning).
2. Native Krylov-Schur Arnoldi and shift-invert for nonsymmetric problems (`nearest(sigma)`, `smallest_magnitude` for general structure, complex shifts).
3. Native Lanczos for matrix-free and composed operators (eigen planner only recognises `dgCMatrix`, `R/problem.R:160`).
4. Sparse Cholesky / LDL' shift-invert via CHOLMOD plus Sylvester inertia: completeness certificates ("exactly j eigenvalues below sigma") and spectrum slicing (`interval(a, b)` target).
5. Promote thick-restart Golub-Kahan (irlba/PROPACK style) as the default sparse SVD; current default squares the condition number.
6. Best-in-class dense drivers: index/value subset selection, `dgesdd`, `dgeevx` with condition numbers, `svd_full()`.

### P1 (parity and differentiators)

7. OpenMP sparse matvec with `eigencore.threads`.
8. Native symmetric-storage `dsCMatrix` kernel (currently expanded, ~2x memory).
9. Davidson family (GD+k / JDQMR) with native preconditioners.
10. Chebyshev-filtered subspace iteration for interior/matrix-free targets.
11. Deflation against user-supplied vectors in Lanczos, Arnoldi, Golub-Kahan.
12. Native `both_ends` and `nearest` Lanczos targets.
13. Sparse general pencils with non-diagonal B.
14. Public C API (`inst/include`, `R_RegisterCCallable`).
15. Adaptive-rank, block-Krylov, single-pass randomized SVD; native matrix-free randomized SVD.
16. `prcomp`-style `pca()` front end.
17. DelayedArray / HDF5Array / bigmemory inputs; nnz > 2^31.
18. `dggsvd3` instead of deprecated `dggsvd`; complex GSVD.
19. Complex sparse and matrix-free solvers (`zgCMatrix`).

### P2

20. Stochastic Lanczos quadrature (log-det, tr f(A)), Hutchinson++, f(A) b.
21. KPM / density-of-states eigenvalue counts to size `k`.
22. Quadratic / polynomial eigenproblems.
23. Eigenvalue condition numbers, Davis-Kahan bounds in certificates, refinement, pseudospectra.
24. float32 / mixed precision; GPU behind the block-operator ABI.
25. Incremental / updated SVD on top of `restart_state`.

## 4. Test coverage gaps

Not covered before this review: `opts`/`sigma` through the shims; double
centering; lower-triangle input; complex Hermitian with repeated eigenvalues;
indefinite `B` in `eig_full`; tiny/huge-norm inputs; NA/Inf input;
