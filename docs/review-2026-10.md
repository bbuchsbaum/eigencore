### Decisions (2026-10-08)

Correctness takes precedence over backward compatibility:

- **C12:** `backward_error` will use the normwise definition
  `||r|| / ((||A||_2 + |lambda| ||B||_2) ||x||)` (SVD: `/ ||A||_2`). The
  denominator uses an `||A||_2` value that never exceeds the true norm: exact
  where cheap (diagonal `max|d|`, dense via the solve's own extreme Ritz value
  when the target includes it), otherwise `max(computed |theta| or sigma,
  short Lanczos/power estimate)`. A lower bound in the denominator makes the
  reported backward error an over-estimate, so `passed` stays sound and is no
  longer up to `sqrt(rank)` more lenient than the standard definition.
  `norm_bound_type` records the source. NEWS will call this out as a
  behaviour change.
- **C15:** `maxit` becomes what its documentation says, an iteration
  (restart) limit. The Krylov subspace size moves to the method descriptors'
  `max_subspace` (already present on `lanczos()`/`golub_kahan()`), and
  RSpectra `opts$ncv` maps there; `opts$maxitr` maps to `maxit`.

## 3. Capability gaps

### P0 (blocks a "premier" claim)

1. **Done (T1):** faithful RSpectra drop-in (`sigma`, `opts`, function input, `lower`, `nu`/`nv`, ordering, non-convergence warning). Remaining divergence: signed `LI`/`SI` (C30).
2. **In progress (T2, with P1):** native Krylov-Schur Arnoldi and shift-invert for nonsymmetric problems (`nearest(sigma)`, `smallest_magnitude` for general structure, complex shifts).
3. Native Lanczos for matrix-free and composed operators (eigen planner only recognises `dgCMatrix`, `R/problem.R:160`).
4. Sparse Cholesky / LDL' shift-invert via CHOLMOD plus Sylvester inertia: completeness certificates ("exactly j eigenvalues below sigma") and spectrum slicing (`interval(a, b)` target). **Phase 1 done (T5):** exported `eigen_count(A, sigma, B)` (dense Bunch-Kaufman, CHOLMOD simplicial LDL' with AMD and symbolic reuse, Sturm for tridiagonal, exact for diagonal, complex Hermitian via the real embedding; reliability diagnostics, perturbation and dense fallback); sparse Hermitian / SPD-pencil shift-invert on CHOLMOD LDL' with validated LU fallback (also sparse non-diagonal SPD `B`); deterministic `inertia_verified` completeness certificates (default `auto` mode, cost gate from `cholmod_analyze`). Internal API for phase 2: `inertia_context()`, `inertia_at()`, `inertia_count_nudged()`, `inertia_interval_count()`, `inertia_factor_cost()` (R/inertia.R). **Phase 2 open:** `interval(a, b)` target and spectrum slicing.
5. Promote thick-restart Golub-Kahan (irlba/PROPACK style) as the default sparse SVD; current default squares the condition number.
6. Best-in-class dense drivers: index/value subset selection, `dgesdd`, `dgeevx` with condition numbers, `svd_full()`.

### P1 (parity and differentiators)

7. OpenMP sparse matvec with `eigencore.threads`.
8. Native symmetric-storage `dsCMatrix` kernel (currently expanded, ~2x memory).
9. Davidson family (GD+k / JDQMR) with native preconditioners.
10. Chebyshev-filtered subspace iteration for interior/matrix-free targets.
11. Deflation against user-supplied vectors in Lanczos, Arnoldi, Golub-Kahan.
12. Native `both_ends` and `nearest` Lanczos targets.
13. Sparse general pencils with non-diagonal B.
14. Public C API (`inst/include`, `R_RegisterCCallable`).
15. Adaptive-rank, block-Krylov, single-pass randomized SVD; native matrix-free randomized SVD.
16. `prcomp`-style `pca()` front end.
17. DelayedArray / HDF5Array / bigmemory inputs; nnz > 2^31.
18. `dggsvd3` instead of deprecated `dggsvd`; complex GSVD.
19. Complex sparse and matrix-free solvers (`zgCMatrix`).

### P2
