# Construct the Euclidean operator induced on a certified PSD image

Construct the Euclidean operator induced on a certified PSD image

## Usage

``` r
psd_reduced_operator(x, A)
```

## Arguments

- x:

  A certified PSD factor.

- A:

  A compatible real-double eigencore operator or matrix.

## Value

An `eigencore_operator` for `R+^T A R+`.
